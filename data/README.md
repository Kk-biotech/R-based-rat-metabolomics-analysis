# Data

## Dataset Source

The metabolomics data analysed in this project are associated with the publicly available MetaboLights study:

**MTBLS1452**

The dataset contains urinary metabolomics data generated from rats subjected to different dietary conditions and sampled at multiple time points.

## Data Used in This Analysis

The analysis focused on selected urinary metabolites and experimental variables relevant to the research questions, including:

- Dietary group
- Sampling time
- Taurine
- Trimethylamine N-oxide (TMAO)
- Valine
- Tryptophan
- Urea

Additional metabolites were explored during the analysis.

## Data Availability

The original dataset should be obtained directly from the official MetaboLights repository.

The raw dataset is not redistributed in this repository unless its redistribution is permitted by the original data source and project conditions.

## Reproducibility

The R analysis script in the `Scripts/` directory contains the statistical analysis and visualization workflow used for this project.

Users wishing to reproduce the analysis should obtain the original dataset from the source repository and adapt the input-file path in the R script as required.
